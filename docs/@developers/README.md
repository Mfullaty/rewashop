# Active eCommerce CMS - Developer Documentation

Welcome to the developer documentation for the **Active eCommerce CMS**. This documentation is intended for developers who want to understand, extend, or maintain the codebase.

## Overview

Active eCommerce CMS is a comprehensive e-commerce platform built on the [Laravel Framework](https://laravel.com/) (version 10.x). It supports features like multi-vendor marketplaces, affiliate systems, POS, auctions, flash deals, and extensive payment gateway integrations.

### Technology Stack
* **Backend Framework:** Laravel 10.x (PHP ^8.2)
* **Frontend Framework:** Vue 2.5, Bootstrap 4, jQuery, compiled via Laravel Mix
* **Database:** MySQL
* **Roles & Permissions:** Spatie Laravel Permission
